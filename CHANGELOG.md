## 0.0.1

* Initial release of `m3e_dropdown_menu`!
* A fully customizable Material 3 Expressive dropdown component with spring physics.
* Supports both single and multi-selection modes.
* Custom chip rendering with scale-in animations for selected items.
* Async future support for fetching remote items seamlessly.
* Integrated search functionality with debouncing support.
* Compatible with form validation and Focus nodes.
